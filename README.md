## 기능

- **지도** — 마커 색이 요리 계통(일식 38 / 유럽 35 / 면류 27 / 중식 6 / 아시아 5). 겹치면 클러스터로 묶이고 클러스터도 그 동네 우세 장르 색을 따른다
- **필터** — 요리 계통 · 가격(¥ / ¥¥) · 행정구 19개 · 이름/주소/요리 검색
- **가까운 순** — 현재 위치를 잡아 거리순 정렬 (HTTPS 필요, 위치 권한 허용 시)
- **상세** — 사진, 일본어 상호, 주소, 전화(탭하면 통화), 미쉐린 인스펙터 코멘트 원문, 구글 길찾기
- **통계** — 요리 종류별 / 행정구별 분포, 구 × 가격대 도트 매트릭스
- 홈 화면에 추가하면 전체화면 앱처럼 뜬다
