## 기능

- **소스 전환** — 빕구르망 / 백명점 세그먼트. 필터·정렬·상세가 소스에 맞게 바뀐다
- **핀에 타베로그 점수** — 누르기 전에 보인다. 4.00 이상 = 전체 상위 0.07%, 3.50 이상 = 상위 3% (카카쿠컴 공식 기준)
- **예약** — 빕구르망은 미쉐린 예약 파트너(TableCheck 28 · OMAKASE 20) → 전화 → 공식 홈페이지 → 타베로그 순 폴백. 111곳 전부 예약 수단 보유. 백명점은 타베로그 예약
- **구글지도** — 빕구르망 111곳은 place ID로 정확한 업장을 연다(저장은 한 번 더 눌러야 함, 구글이 저장 API 미공개)
- **필터** — 빕구르망: 요리 계통·가격·구·정렬 / 백명점: 35개 장르·점수 구간·구·정렬
- **가까운 순** — 현재 위치 기준 거리 정렬 (양쪽 다)

## 갱신

미쉐린은 연 1회, 타베로그 점수는 매월 제1·제3 화요일, 백명점은 장르별로 수시 발표된다.
`index.html` 안의 `<script id="payload">`(빕구르망) / `<script id="payload2">`(백명점) JSON만 교체하면 된다.
